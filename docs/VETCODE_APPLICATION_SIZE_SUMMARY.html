Counting Rules

Included

.py, .html, .js, .css, .svg, .txt, and .md files under app-owned roots such as backend, scripts, frontend, ui, and docs.

Excluded

.venv, node_modules, .git, caches, export folders, calendar tokens, QA artifacts, and uploaded resume/document files. These are runtime/generated/user files, not application source.

Database Definition

The database-like store count includes configured Azure PostgreSQL, local SQLite .db files, and JSON operational stores. JSON “fields” are distinct key names recursively found in those stores.
