What this proves

This demo makes the IP visible: Egeria captures a real intake, turns it into a job description, reads live DevReady profile evidence, prepares a match/scheduling handoff, and uses OpenAI to generate a buyer-safe interview draft without sending it.

The terminal is idle until you run it. Use Simulation for a quick visual story, E2E Test for platform readiness, or AI Proof to show the actual inputs, OpenAI-backed draft output, model/config status, and workflow evidence a buyer can inspect.

AI proof trail

Shows what the AI evaluated, which platform endpoint produced it, and whether OpenAI-backed work returned usable output.

1. The agent reads the live packet It does not start from a generic demo. It pulls the latest Call Ask, saved JD, profile evidence, and interview archive context. agent-handoff.html -> buildHandoffPacket()
2. The API verifies AI readiness The page checks whether OpenAI and the voice provider are configured server-side without exposing secrets to the browser. main.py -> _call_intake_env_status()
3. OpenAI receives structured context The interview draft endpoint sends role, company, JD text, profile context, attendees, and rules to OpenAI for a strict JSON draft. calendar_router.py -> invite_draft()
4. The result becomes workflow output The returned AI draft is rendered as proof: title, subject, agenda, body preview, model/config status, and elapsed time. agent-handoff.html -> runAiProofEvaluation()
